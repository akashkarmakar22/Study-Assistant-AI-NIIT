# 🤖 AI Study Assistant

An AI-powered study assistant designed to help students learn, understand, and interact with educational content through an intuitive web interface.

The project combines a modern frontend with a Python-based backend to provide an interactive learning experience and AI-assisted educational features.

## 📌 Overview

**AI Study Assistant** is a web-based educational application built to make studying more interactive and accessible.

The platform provides students with an AI-powered environment where they can interact with learning resources, ask questions, and receive intelligent assistance.

The project follows a **frontend + backend architecture**, making it easier to maintain, extend, and integrate additional AI capabilities in the future.
